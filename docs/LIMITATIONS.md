# 已知限制与排障

## 产品边界（不是待实现功能）

永不提供代码编辑、VCS 写操作、合并、冲突解决或 PR/MR 管理。vividiff 只读取来源，并写入自己的评审数据。

## v0.1 限制

- Windows 首发。macOS/Linux 不属于 M5 验收。
- 安装包未签名；SmartScreen 可能提示。没有自动更新和插件市场。
- 源文件必须是 UTF-8（可带 BOM）或带 BOM 的 UTF-16。其他编码及二进制明确降级，不猜测编码。
- 单文件预览上限 2 MiB，文本总量上限 24 MiB，单次最多 3000 个变更路径。
- 二进制、超大文件、子模块只显示类型／元数据，不提供文本行批注。超出预览限制的内容不保存完整字节；文件级批注仍可保存，但不能宣称能重建其二进制原文。
- 约 300,000 字符以上跳过语法高亮。差异计算有复杂度和时间限制，复杂大文件可能提示处理超时。
- 比较工作区采用双次读取检测变化，不能保证其他进程并发修改时跨文件原子一致；检测到变化会要求重试。
- 源捕获串行写入服务，后续请求可能排队；“停止等待”不会撤销已经开始的捕获。Git 子命令 30 秒超时、插件请求 120 秒超时。代码 Worker 切换文件时会终止。
- 大文件列表当前使用滚动列表；代码行使用虚拟列表。性能样本和实际测量见 STATUS.md。
- 跨版本定位采取保守策略：相同内容摘要，或完整上下文唯一匹配才显示派生定位；复杂移动／重命名不保证迁移成功，始终可查看原始上下文。
- 已保存批注持久化；尚未点击保存的输入不会跨应用退出自动恢复。切换语言不会清空输入，切换评审／快照会要求先保存或放弃。
- 本机应用窗口关闭后服务继续运行。无系统托盘或自动退出定时器；可通过任务管理器结束仅属于 vividiff 的服务进程，下次启动恢复。
- 本地数据未加密，桌面凭据用于接口职责隔离而非抵御相同 OS 用户。不要让其他用户读取应用数据目录。
- 第三方 VCS 插件拥有用户权限，任何权限清单仅为声明，不是系统沙箱。
- 界面语言文件支持扩展；RTL 布局尚未验收。
- 当前 MCP 自动化验证覆盖标准 stdio 客户端交互；各厂商真实 Agent 的安装配置差异需要接入时验证，不能推断所有客户端均已认证。

## 排障

### 桌面无法启动

确认 WebView2 Runtime 已安装。开发环境需 Visual Studio C++ Build Tools。sidecar 必须与桌面 exe 同目录；请用 desktop:dev/build 脚本，不要跳过 sidecar 构建直接运行 Tauri。

### Git 批处理失败

使用 Git 2.42+，确认 git 在 PATH 中。仓库缺失或对象不完整时只报错，不自动 clone/fetch。先让 Agent 在外部修复来源再重试。

### Agent 创建成功但窗口未打开

先打开桌面应用一次以注册路径，确认桌面与 CLI 的 VIVIDIFF_DATA_DIR 相同。查看返回的 desktop.opened / reason，再调用 review_open。

### 内容捕获失败

查看错误的技术详情。SOURCE_CHANGED 表示双次扫描不一致；RESOURCE_LIMIT 表示超过预览上限；TIMEOUT 表示只读命令或插件未及时退出。没有任何自动回退／重置仓库动作。

### 构建报 core/std metadata 或 mspdbcore.dll 1455

Windows 提交内存不足可表现为这些错误。项目已限制 Cargo 并行度为 2；仍不足时使用 CARGO_BUILD_JOBS=1。不要通过修改 Rust 源码或删除系统工具链规避内存问题。

### 插件与语言错误

设置页显示诊断。验证 JSON、schema/protocolVersion、唯一 ID/locale、路径没有逃出插件目录。移除损坏的外部语言后使用英文降级；不需要删除评审数据库。
