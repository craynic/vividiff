## 实施调整

- 内容快照采用 SQLite 内部去重块与引用表，替代独立快照文件，使删除/恢复/完成事务更简单。
- 插件 v1 批量返回变更文件及冻结内容，避免逐文件 IPC；Git 对象读取使用 cat-file 批处理。
- 可执行插件保留本机信任边界；不宣称进程隔离等于沙箱。
- Git 不自动下载缺失对象；源异常由 Agent 在工具外处理。
- 只打包常见高亮语言及一个内置主题，其余可用资源插件添加，避免全量语言包进入安装包。
- 编译时曾遇到本机提交内存不足；项目限制 Cargo jobs=2，桌面入口包使用较低优化等级降低嵌入资源的编译开销，核心服务及依赖仍优化构建。
